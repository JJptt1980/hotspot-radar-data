# 熱點雷達資料檔

熱點雷達 App 的公開資料和問題回報都在這裡。「門牌包」放在這裡的 Release，App 在設定 → 關於可以直接下載，裝過的人開 App 時也會自動檢查有沒有新版。

## 隱私（最優先）

- 你的行車位置、行程記錄、收入、錄音都只存在你自己的手機上。開發者沒有架伺服器收資料，App 也沒有把這些傳給開發者的功能。
- 要備份時，是存到**你自己的** Google Drive，或匯出成檔案自己保管。
- 車機模式按「!」記下的問題回報（那段時間的定位、畫面判斷、錄音）也只存在你的手機，不會自動上傳。
- App 會上網下載的只有公開資料：測速照相、國道路況等政府開放資料、這裡的門牌包，以及地圖圖塊（OpenStreetMap／OpenFreeMap，跟一般地圖 App 一樣，地圖伺服器會知道你在看哪一區的地圖）。

## 回報問題

1. 開車時覺得哪裡怪怪的，按車機畫面左上角的「!」，App 會記下那段時間的判斷。
2. 停好車，到 App 的 設定 → 車機模式 → 問題回報，按「到 GitHub 回報」。
3. 瀏覽器會打開這裡的 [新 Issue](https://github.com/JJptt1980/hotspot-radar-data/issues/new) 頁，已經幫你填好版本、時間、手機型號，寫下發生什麼事就可以送出（需要 GitHub 帳號）。

**這裡的 Issue 全世界都看得到。** App 只帶上面那幾行文字，**不會附上你的行車位置、路名和錄音**。描述時要不要寫在哪裡，由你自己決定；不想公開的地點就不要寫。

## 門牌包（addr-pack.zip）

全台門牌位置（車機模式的單雙號、找門牌用）、全台路名與限速、快速道路。

資料來源：

- 各縣市政府在政府資料開放平臺公開的門牌坐標資料（政府資料開放授權條款第 1 版）
- 基隆市、宜蘭縣、南投縣、嘉義市、連江縣：政府門牌資料，經 [monkey1wizard/taiwan-address-data](https://github.com/monkey1wizard/taiwan-address-data) 整理（宜蘭、南投、嘉義市、連江是 2016 年的資料）
- 路名、限速、快速道路，以及部分門牌：© OpenStreetMap contributors（[ODbL](https://opendatacommons.org/licenses/odbl/)）

`meta.json` 是門牌包的版本資訊（`built` 是打包時間），App 用它判斷要不要更新。
